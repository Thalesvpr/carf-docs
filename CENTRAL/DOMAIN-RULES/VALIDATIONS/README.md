# VALIDATIONS

Regras de validacao de dados especificas do dominio REURB. Validacoes de negocio que vao alem de formato basico, garantindo integridade de dados e compliance com requisitos legais de regularizacao fundiaria.

As validacoes de [negocio](./01-business-validation.md) cobrem regras como transicoes de status, unicidade de identificadores e restricoes de titularidade. Validacoes [geograficas](./07-geographic-validation.md) garantem integridade espacial incluindo deteccao de sobreposicao e limites de area. Regras especificas para [titulares](./09-holder-validation.md) validam CPF, dados pessoais e vinculos com unidades. Validacoes de [unidades](./11-unit-validation.md) verificam geometria, documentacao e limites conforme modalidade REURB.
