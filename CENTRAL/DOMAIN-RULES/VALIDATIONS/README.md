# VALIDATIONS

Regras de validacao de dados especificas do dominio REURB. Validacoes de negocio alem de formato basico.
## Proposito

Regras de validacao de negocio como:
- Limites de area por modalidade REURB
- Restricoes de titularidade
- Validacoes espaciais (sobreposicao, confinamento)
- Consistencia entre entidades relacionadas
