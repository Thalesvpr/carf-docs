# Notificacoes

Requisitos funcionais para sistema de notificacoes do ecossistema CARF. Define mecanismos de comunicacao in-app para manter usuarios informados sobre acoes relevantes em seu workflow de trabalho.

O requisito [RF-033](./RF-033-notificações-in-app.md) especifica notificacoes in-app incluindo badge de contador, painel cronologico de notificacoes, marcacao de lido/nao-lido e navegacao contextual para recursos relacionados. Sistema de eventos backend publica notificacoes consumidas pelo frontend via polling ou WebSocket.
