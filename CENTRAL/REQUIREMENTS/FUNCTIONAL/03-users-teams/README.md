# Usuarios e Equipes

Requisitos funcionais para gerenciamento de usuarios e equipes no ecossistema CARF. Define operacoes de cadastro, edicao, desativacao e listagem de usuarios com atribuicao de roles, alem de organizacao em equipes para segregacao logica de responsabilidades e comunidades.

Os requisitos [RF-021](./RF-021-criar-usuário.md) a [RF-025](./RF-025-atribuir-role-a-usuário.md) cobrem ciclo de vida de usuarios incluindo criacao com email de boas-vindas, edicao de dados, desativacao via soft delete, listagem paginada com filtros e atribuicao de roles hierarquicas. Os requisitos [RF-026](./RF-026-criar-equipe-team.md) a [RF-030](./RF-030-filtrar-comunidades-por-equipe.md) definem gestao de equipes permitindo agrupar usuarios e vincular comunidades especificas. Os requisitos [RF-031](./RF-031-perfil-de-usuário.md) e [RF-032](./RF-032-redefinir-senha.md) tratam de autogestao do usuario incluindo perfil e recuperacao de senha.
