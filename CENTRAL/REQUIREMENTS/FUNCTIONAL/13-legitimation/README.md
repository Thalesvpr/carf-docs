# Processos de Legitimacao

Requisitos funcionais para gerenciamento de processos de legitimacao fundiaria no ecossistema CARF. Processos formalizam tramitacao administrativa de regularizacao territorial conforme Lei 13465/2017 (REURB-S e REURB-E), integrando dados cadastrais, documentais e geoespaciais.

Os requisitos [RF-172](./RF-172-criar-processo-de-legitimação.md) a [RF-175](./RF-175-status-de-processo.md) cobrem ciclo de vida basico do processo incluindo criacao, edicao, listagem e transicoes de status com workflow estruturado. Os requisitos [RF-176](./RF-176-anexar-documentos-ao-processo.md) a [RF-178](./RF-178-assinatura-digital-de-termo.md) tratam documentacao probatoria, geracao de termos oficiais e assinatura digital ICP-Brasil. Os requisitos [RF-179](./RF-179-timeline-de-processo.md) a [RF-181](./RF-181-relatório-de-processos.md) fornecem rastreabilidade atraves de timeline historica, notificacoes automaticas e relatorios gerenciais.
