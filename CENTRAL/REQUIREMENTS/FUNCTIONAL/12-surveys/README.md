# Levantamentos Topograficos

Requisitos funcionais para gerenciamento de levantamentos topograficos no ecossistema CARF. Define operacoes de criacao, importacao, processamento e exportacao de dados topograficos incluindo pontos, curvas de nivel e modelos de elevacao, conforme WORKFLOW-MESTRE onde dados de campo sao coletados e processados para suporte a regularizacao fundiaria.

Os requisitos [RF-157](./RF-157-criar-levantamento.md) a [RF-159](./RF-159-listar-levantamentos.md) cobrem ciclo de vida de levantamentos. Os requisitos [RF-160](./RF-160-importar-pontos-de-levantamento.md) a [RF-161](./RF-161-visualizar-pontos-no-mapa.md) tratam importacao e visualizacao de pontos. Os requisitos [RF-162](./RF-162-gerar-curvas-de-nível.md) a [RF-164](./RF-164-calcular-perfil-topográfico.md) cobrem analises altimetricas (curvas, MDE, perfil). Os requisitos [RF-165](./RF-165-ajustar-sistema-de-coordenadas.md) a [RF-168](./RF-168-validar-fechamento-de-poligonal.md) tratam ajustes e validacoes tecnicas. Os requisitos [RF-169](./RF-169-integração-com-estação-total.md) e [RF-170](./RF-170-integração-com-gnss.md) definem integracoes com equipamentos. O requisito [RF-171](./RF-171-dashboard-de-levantamentos.md) apresenta dashboard de estatisticas.
