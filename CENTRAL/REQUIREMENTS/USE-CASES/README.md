# USE-CASES

Casos de uso do CARF documentando fluxos de negocio que atravessam multiplos projetos. Cada caso de uso possui atores definidos, objetivo claro, pre-condicoes, fluxo principal passo-a-passo, fluxos alternativos para variacoes, fluxos de excecao para erros, e pos-condicoes garantidas apos execucao.

Exemplos incluem [cadastrar unidade habitacional](./UC-001-cadastrar-unidade-habitacional/README.md) onde GEOWEB cadastra, GEOAPI valida, REURBCAD sincroniza e GEOGIS visualiza. Ou [coletar dados em campo](./UC-004-coletar-dados-campo-mobile/README.md) com sincronizacao offline. Ou [gerar relatorio de comunidade](./UC-006-gerar-relatorio-comunidade/README.md) agregando dados de multiplas fontes.

Atualmente existem 11 casos de uso documentados cobrindo desde autenticacao e cadastro ate exportacao de dados e processo de legitimacao fundiaria conforme Lei 13.465/2017.
