# UC-007: Exportar Dados Geograficos

Caso de uso para exportacao de unidades habitacionais em formatos GIS padrao. O fluxo envolve ANALYST ou MANAGER selecionando filtros e formato de saida (Shapefile, GeoJSON, KML, CSV, Excel) para uso em ferramentas externas.

O [fluxo principal](./UC-007-exportar-dados-geograficos.md) documenta a exportacao completa. Os fluxos alternativos cobrem exportacao rapida para poucos dados (FA-001) e exportar selecao de unidades especificas (FA-002). Os fluxos de excecao tratam limite excedido (FE-001), geometrias invalidas (FE-002) e erro de reprojecao (FE-003).
