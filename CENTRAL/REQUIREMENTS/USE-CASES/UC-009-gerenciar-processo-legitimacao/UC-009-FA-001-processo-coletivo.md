# UC-009-FA-001: Processo Coletivo (Multiplas Unidades)

Fluxo alternativo do UC-009 para criar processo de legitimacao envolvendo multiplas unidades.

## Condicao

No passo 5 do UC-009, usuario seleciona modalidade Coletiva ao inves de Individual.

## Fluxo

1. Usuario seleciona modalidade Coletiva
2. Sistema expande formulario com secao de adicao de unidades
3. Usuario busca unidades por codigo, endereco ou comunidade
4. Sistema exibe unidades aprovadas elegiveis
5. Usuario seleciona multiplas unidades adjacentes
6. Sistema vincula unidades ao processo
7. Sistema exibe checklist compartilhada de documentos
8. Usuario anexa documentos gerais e especificos por unidade
9. Termo gerado consolida todas unidades em unico documento

## Vantagens

- Reducao de burocracia para areas homogeneas
- Documentos gerais compartilhados entre unidades
- Economia em custos de cartorio
- Aceleracao da regularizacao em assentamentos

## Retorno

Processo criado com multiplas unidades vinculadas. Termo consolida todas em documento unico.
