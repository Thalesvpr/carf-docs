# Confiabilidade

Requisitos de confiabilidade do CARF definindo disponibilidade, recuperacao de falhas e continuidade operacional. Cada requisito especifica metricas de SLA e procedimentos que garantem operacao consistente do sistema.

Os requisitos cobrem [uptime](./RNF-036-uptime.md) e [recuperacao de falhas](./RNF-037-recuperacao-automatica-falhas.md), [backup de dados](./RNF-038-backup-automatico-dados.md) com objetivos de [RPO](./RNF-039-rpo-objetivo-ponto-recuperacao.md) e [RTO](./RNF-040-rto-objetivo-tempo-recuperacao.md), alem de [degradacao graciosa](./RNF-041-degradacao-graciosa-sistema.md), [deploy zero-downtime](./RNF-042-deploy-zero-downtime.md), [monitoramento de erros](./RNF-043-monitoramento-erros-aplicacao.md), [validacao de integridade](./RNF-045-validacao-integridade-dados.md), [undo/redo](./RNF-051-undo-redo-acoes.md), [atalhos de teclado](./RNF-055-atalhos-teclado.md) e [rollback de deploy](./RNF-065-rollback-de-deploy.md).
