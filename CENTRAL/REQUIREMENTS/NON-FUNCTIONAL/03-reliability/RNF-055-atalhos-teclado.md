# RNF-055: Atalhos de Teclado

## Descricao

GEOWEB deve implementar atalhos de teclado para acoes frequentes. Permite usuarios avancados operarem mais eficientemente seguindo convencoes estabelecidas.

## Metricas

- Compatibilidade: Ctrl (Windows) / Cmd (macOS)
- Atalhos globais: Ctrl+S (salvar), Ctrl+F (buscar), Esc (fechar)
- Documentacao: listagem via Ctrl+? ou Ctrl+/

## Criterios de Aceitacao

1. Ctrl+S salva formulario atual com feedback visual
2. Esc fecha modais e overlays consistentemente
3. Listagem de atalhos acessivel organizada por categoria
