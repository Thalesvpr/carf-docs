# RNF-053: Onboarding

## Descricao

GEOWEB deve oferecer tour guiado interativo para novos usuarios apresentando principais funcionalidades. Reduz curva de aprendizado inicial.

## Metricas

- Tour: 5-8 passos cobrindo funcionalidades principais
- Tooltips: minimo 10 em funcionalidades nao-obvias
- Biblioteca: react-joyride ou intro.js

## Criterios de Aceitacao

1. Tour ativado automaticamente no primeiro acesso
2. Botao "Pular Tour" visivel em cada passo
3. Opcao no perfil para reativar tour manualmente
