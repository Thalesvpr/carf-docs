# RNF-052: Consistencia de UI

## Descricao

Interface deve seguir design system consistente aplicado uniformemente em GEOWEB e REURBCAD. Reduz carga cognitiva eliminando variacoes arbitrarias.

## Metricas

- Componentes: biblioteca com minimo 15 componentes reutilizaveis
- Espacamento: escala baseada em multiplos de 8px
- Documentacao: Storybook ou similar

## Criterios de Aceitacao

1. Paleta de cores documentada (primaria, secundaria, semanticas)
2. Componentes usados em pelo menos 80% das telas
3. Escala tipografica com 4-5 niveis de heading
