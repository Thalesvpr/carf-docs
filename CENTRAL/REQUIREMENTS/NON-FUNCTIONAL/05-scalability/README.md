# Escalabilidade

Requisitos nao-funcionais de escalabilidade definem capacidades do sistema para crescer em volume de dados, usuarios e carga. Inclui estrategias de escala horizontal, cache distribuido, filas de processamento e preparacao para sharding.

Esta pasta contem 19 RNFs organizados por tema: [Upload de Arquivos](./RNF-006-upload-arquivos.md), [Sincronizacao Offline](./RNF-009-sincronizacao-offline-push.md), [Cache de Dados](./RNF-012-cache-dados.md), [Consumo de Memoria](./RNF-013-consumo-memoria-backend.md), [Rate Limiting](./RNF-021-rate-limiting.md), [Protecao CSRF](./RNF-026-protecao-csrf.md), [Permissoes Granulares](./RNF-032-permissoes-granulares.md), [Observabilidade](./RNF-061-observabilidade.md), [Escala Horizontal](./RNF-071-escala-horizontal-backend.md), [Usuarios Simultaneos](./RNF-072-usuarios-simultaneos.md), [Volume Unidades](./RNF-073-volume-de-dados-unidades.md), [Volume Arquivos](./RNF-074-volume-dados-arquivos.md), [Pico de Carga](./RNF-075-pico-carga.md), [Conexoes Banco](./RNF-076-conexoes-banco.md), [Cache Distribuido](./RNF-077-cache-distribuido.md), [Job Queue](./RNF-078-job-queue.md), [Rate Sincronizacao](./RNF-079-rate-sincronizacao.md), [Database Sharding](./RNF-080-database-sharding.md) e [Webhooks](./RNF-087-webhooks.md).
