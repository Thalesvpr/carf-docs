# RNF-030: Protecao de Dados Pessoais (LGPD)

## Descricao

Sistema deve estar em conformidade com LGPD (Lei 13.709/2018), garantindo direitos dos titulares de dados pessoais. Inclui consentimento, portabilidade e direito ao esquecimento.

## Metricas

- Lei: LGPD (Lei 13.709/2018)
- Portabilidade: exportacao em JSON ou CSV
- Logs: acesso a dados pessoais auditado

## Criterios de Aceitacao

1. Consentimento explicito coletado para processamento de dados
2. Funcionalidade de exclusao completa (direito ao esquecimento)
3. Endpoint de exportacao de dados pessoais do titular
