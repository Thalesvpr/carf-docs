# Compatibilidade

Requisitos nao-funcionais de compatibilidade definem interoperabilidade com formatos de dados, sistemas de coordenadas e padroes da industria GIS. Garante integracao com ferramentas existentes e migracao de dados legados.

Esta pasta contem 7 RNFs: [Exportacao de Dados](./RNF-007-exportacao-dados.md), [Sincronizacao Offline Pull](./RNF-008-sincronizacao-offline-pull.md), [Logs Estruturados](./RNF-044-logs-estruturados-centralizados.md), [Linting e Formatacao](./RNF-058-linting-e-formatacao.md), [Formatos de Importacao](./RNF-081-formatos-importacao.md), [Sistemas de Coordenadas](./RNF-083-sistemas-coordenadas.md) e [Integracao WMS/WMTS](./RNF-084-integracao-wms-wmts.md).
