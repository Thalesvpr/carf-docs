# WEBDOCS

Portal de documentacao tecnica construido com Astro 4 e Starlight hospedando guias de usuario, manuais de operacao, documentacao de API e referencias tecnicas do ecossistema CARF. Serve como ponto central de consulta para usuarios finais e desenvolvedores.

Stack com Astro para geracao estatica, Starlight para tema de documentacao, MDX para conteudo rico, Pagefind para busca client-side e Decap CMS para edicao por nao-desenvolvedores. Autenticacao Keycloak para areas restritas com conteudo especifico por role.

## Capacidades

Navegacao estruturada por perfil de usuario com guias para analistas, agentes de campo e administradores. Documentacao de API com Swagger embutido. Diagramas Mermaid renderizados automaticamente. Busca full-text instantanea. Status page com disponibilidade dos servicos. Versionamento de conteudo. Detalhes tecnicos no repositorio carf-webdocs.
