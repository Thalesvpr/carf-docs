# RELEASES

Documentacao de estrategia e coordenacao de releases do ecossistema polyrepo CARF, garantindo compatibilidade entre os sete repositorios independentes e deployments coordenados.

A [estrategia polyrepo](./01-polyrepo-strategy.md) justifica a arquitetura de repositorios independentes explicando vantagens de deploy separado, ownership claro por time e CI/CD otimizado, alem de documentar estrutura de diretorios e workflow de trabalho. A [coordenacao de releases](./02-release-coordination.md) define processo de preparacao, validacao e deploy de novas versoes incluindo ordem de deploy, smoke tests e procedimentos de rollback.

A [matriz de compatibilidade](./03-compatibility-matrix.md) documenta quais versoes dos projetos sao compativeis entre si, servindo como referencia para deployments e troubleshooting de integracoes.
