# COMPLIANCE

Documentacao de conformidade regulatoria do sistema CARF focada em LGPD.

O documento [01-lgpd-overview](./01-lgpd-overview.md) apresenta uma visao geral dos controles implementados para atender a Lei Geral de Protecao de Dados (Lei 13.709/2018), incluindo gestao de consentimento, direitos dos titulares, DPO designado e procedimentos de breach notification.

A politica detalhada de compliance LGPD esta em [POLICIES/04-lgpd-compliance-policy](../POLICIES/04-lgpd-compliance-policy.md). Os procedimentos de notificacao de breach estao em [INCIDENTS/03-breach-notification](../INCIDENTS/03-breach-notification.md).
