# Hierarquia Tipografica

Titulos obviamente maiores que corpo. Corpo confortavel para leitura prolongada. Texto secundario menor mas legivel. Se dois niveis parecem iguais, a hierarquia falhou.

## Niveis

| Nivel | Proposito | Caracteristica |
|-------|-----------|----------------|
| H1 | Titulo de pagina | Maior, bold, unico por tela |
| H2 | Secoes principais | Grande, bold |
| H3 | Subsecoes | Medio, bold ou semi-bold |
| Corpo | Texto principal | Tamanho base, peso normal |
| Legenda | Texto auxiliar | Menor, cinza, metadados |

## Uso

Cada tela tem exatamente um H1. Secoes importantes usam H2. Subdivisoes dentro de secoes usam H3. Nao pule niveis - se tem H3, deve ter H2 acima.

## Cuidados

Evite mais de quatro niveis na mesma tela. Hierarquia profunda demais indica interface complexa demais. Considere dividir em telas separadas.
