# Aplicacao Tipografica

Regras especificas para cada contexto de interface. O objetivo e consistencia - o usuario nao deve perceber variacao entre modulos.

## Elementos

| Elemento | Regra |
|----------|-------|
| Labels | Acima ou ao lado do campo, peso medio |
| Campos | Mesmo tamanho do corpo, placeholder mais suave |
| Mensagens | Tamanho padrao, cor indica tipo |
| Botoes | Peso medio ou bold, proporcional ao tamanho |
| Tabelas | Cabecalho bold, linhas com fundo alternado |
| Links | Mesmo tamanho do texto ao redor, azul, sublinhado no hover |
| Badges | Menor que corpo, uppercase opcional para status |

## Cuidados

Nunca use italico para enfase - reserve para citacoes ou termos tecnicos. Bold e suficiente para destacar. Evite texto todo em maiusculas exceto em badges e labels curtos.
