# Agrupamentos

Proximidade comunica relacao. Elementos relacionados ficam proximos. Elementos nao relacionados ficam distantes.

## Hierarquia

- Pequeno: entre elementos do mesmo grupo
- Medio: entre grupos da mesma secao
- Grande: entre secoes diferentes

Nao use bordas ou caixas quando espacamento resolve. Espaco em branco e elemento de design.
