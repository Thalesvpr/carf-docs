# Cinza

Cor neutra do sistema. Usado para elementos secundarios, estados desabilitados e informacoes de menor prioridade.

## Uso

- Textos secundarios e descricoes
- Bordas e separadores
- Elementos desabilitados
- Fundos de areas secundarias
- Icones de funcoes menos importantes
- Placeholders em campos de formulario

## Cuidados

Cinza nao deve ser tao claro que se torne invisivel nem tao escuro que compita com texto principal. O contraste deve ser suficiente para leitura, especialmente em telas sob luz solar. Elementos desabilitados em cinza devem parecer claramente inativos, nao apenas apagados.

Use tons de cinza para criar hierarquia visual - cinza mais escuro para informacoes mais relevantes, mais claro para menos relevantes.
