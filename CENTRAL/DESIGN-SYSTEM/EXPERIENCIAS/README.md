# EXPERIENCIAS

Momentos-chave na jornada do usuario onde o design tem impacto critico. Cada experiencia representa um contexto especifico com necessidades, restricoes e emocoes proprias que o design deve enderecar.

Nao desenhamos telas - desenhamos experiencias. Uma tela de cadastro e diferente para um agente em campo sob sol do que para um analista no escritorio. Entender o momento completo permite criar solucoes que realmente funcionam.

O [primeiro acesso](./01-primeiro-acesso.md) define como acolhemos novos usuarios. A [coleta em campo](./02-coleta-campo.md) aborda os desafios unicos do agente trabalhando in loco. A [analise em mesa](./03-analise-mesa.md) foca na eficiencia do analista processando cadastros. O [feedback de status](./04-feedback-status.md) trata como comunicamos decisoes que afetam vidas. A [recuperacao de erro](./05-erro-recuperacao.md) guia como ajudamos quando algo da errado.
