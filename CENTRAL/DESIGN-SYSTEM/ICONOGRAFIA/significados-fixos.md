# Significados Fixos

Alguns icones tem significado imutavel no sistema. Subverter esses padroes estabelecidos causa confusao desnecessaria. O usuario ja conhece essas convencoes de outros aplicativos.

## Navegacao

- **Casa** = inicio, pagina principal, home
- **Seta para esquerda** = voltar
- **Tres linhas horizontais** = menu (hamburger)
- **X** = fechar

## Acoes Comuns

- **Lupa** = busca, pesquisa
- **Engrenagem** = configuracoes
- **Pessoa** = perfil, usuario
- **Lixeira** = excluir
- **Lapis** = editar
- **Mais** (+) = adicionar, criar novo

## Dominio Especifico

Icones especificos do dominio de regularizacao fundiaria devem ser estabelecidos uma vez e usados consistentemente:

- Simbolos de geometria para lotes e parcelas
- Icones de mapa para localizacao
- Icones de documento para processos e cadastros
- Icones de camera para fotos e evidencias

Esses icones especificos devem ser documentados conforme o ecossistema evolui.
