# IDENTIDADE

Quem e o CARF visualmente. A identidade define a personalidade do sistema - como ele se apresenta, como fala, que impressao deixa. Nao sao apenas escolhas esteticas, sao decisoes sobre como queremos ser percebidos.

O CARF precisa equilibrar duas forcas aparentemente opostas. De um lado, a seriedade institucional de um sistema governamental que lida com documentos oficiais e processos legais. Do outro, o acolhimento necessario para atender pessoas em situacao vulneravel sem intimida-las.

A [marca](./01-marca.md) define a personalidade e o significado por tras do nome CARF. As [cores](./02-cores.md) explicam o que cada cor transmite emocionalmente e quando usar cada uma. A [tipografia](./03-tipografia.md) estabelece como a escolha de fontes reforca clareza e hierarquia. O [tom de voz](./04-tom-voz.md) guia como o sistema se comunica em cada situacao.
