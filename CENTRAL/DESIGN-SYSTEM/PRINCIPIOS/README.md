# PRINCIPIOS

Fundamentos que guiam todas as decisoes de design no ecossistema CARF. Estes principios existem antes de qualquer cor, fonte ou componente - sao a razao pela qual o design e como e.

O CARF atende pessoas em processo de regularizacao fundiaria, muitas em situacao de vulnerabilidade social buscando legitimacao de suas moradias. O design precisa servir a essas pessoas com dignidade, clareza e respeito, ao mesmo tempo que transmite a seriedade institucional de um sistema governamental.

A [visao](./01-visao.md) define qual experiencia queremos criar para cada pessoa que interage com o sistema. Os [valores](./02-valores.md) estabelecem os pilares de confianca, clareza e acolhimento que permeiam cada decisao visual. O compromisso com [acessibilidade](./03-acessibilidade.md) garante que o sistema seja utilizavel por todos, independente de limitacoes. O [contexto de uso](./04-contexto-uso.md) reconhece as diferentes realidades onde o sistema sera usado - do escritorio climatizado ao campo sob sol forte.
