# Valores

Tres valores fundamentam cada decisao de design no CARF. Nao sao apenas palavras - sao criterios praticos para avaliar se uma solucao esta no caminho certo.

Confianca institucional significa que o sistema deve parecer oficial, serio e permanente. Pessoas estao confiando seus dados pessoais e o futuro de suas moradias a este sistema. Cores solidas, tipografia clara e linguagem precisa transmitem que ha uma instituicao responsavel por tras. Nada de modismos visuais ou informalidade excessiva.

Clareza absoluta significa que nenhuma pessoa deveria precisar adivinhar o que fazer em seguida. Processos burocraticos ja sao confusos por natureza - o design nao pode adicionar mais confusao. Hierarquia visual evidente, linguagem simples e feedback imediato guiam o usuario sem ambiguidade.

Acolhimento respeitoso significa tratar cada usuario com dignidade, especialmente aqueles em situacao vulneravel. O sistema nao julga, nao intimida, nao presume conhecimento previo. Mensagens de erro orientam ao inves de culpar. Estados vazios encorajam ao inves de frustrar. O tom e sempre de parceria.
