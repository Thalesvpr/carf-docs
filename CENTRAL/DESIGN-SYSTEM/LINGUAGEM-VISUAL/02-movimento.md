# Movimento

Movimento e funcional, nunca decorativo. Feedback de acao e instantaneo. Transicoes sao suaves mas rapidas.

## Quando nao animar

Carregamento: indicador simples. Listas longas: aparecem de uma vez. Acoes criticas: sem atraso na confirmacao.

Respeite preferencias de sistema para movimento reduzido.
