# LINGUAGEM-VISUAL

Como as coisas parecem e se comportam no CARF. A linguagem visual traduz os principios e a identidade em decisoes concretas sobre espacamento, profundidade, movimento e simbolos.

Cada elemento visual comunica algo. Espaco em branco transmite organizacao e respiro. Sombras indicam hierarquia e foco. Movimento confirma que acoes foram registradas. Icones aceleram reconhecimento de funcoes familiares. Nada e decorativo por acaso - tudo serve a clareza.

O [espacamento](./01-espacamento.md) define como elementos respiram e se agrupam para criar organizacao visual. A [profundidade](./02-profundidade.md) estabelece camadas e hierarquia atraves de sombras e sobreposicoes. O [movimento](./03-movimento.md) guia o uso de animacoes e transicoes para feedback e orientacao. A [iconografia](./04-iconografia.md) define o estilo e uso de simbolos visuais.
