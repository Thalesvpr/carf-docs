# GITHUB

Documentação prática de configuração e uso do GitHub no projeto CARF, complementando a decisão estratégica em 02-github-decision.md com guias operacionais detalhados.

A [configuração de organização](./01-organization-setup.md) define estrutura de times, permissões e políticas de acesso aos repositórios. As [configurações de repositório](./02-repository-settings.md) padronizam settings como branch default, merge options e features habilitadas em cada repo. A [proteção de branches](./03-branch-protection.md) especifica regras para main incluindo reviews obrigatórios, status checks e restrições de push.

Os [workflows de Actions](./04-actions-workflows.md) documentam pipelines CI/CD para build, test, lint e deploy de cada projeto. As [features de segurança](./05-security-features.md) cobrem Dependabot, CodeQL, secret scanning e políticas de vulnerabilidades.
