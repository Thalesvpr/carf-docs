# RELEASES

Documentação de estratégia e coordenação de releases do ecossistema polyrepo CARF, garantindo compatibilidade entre os sete repositórios independentes e deployments coordenados.

A [estratégia polyrepo](./01-polyrepo-strategy.md) justifica a arquitetura de repositórios independentes explicando vantagens de deploy separado, ownership claro por time e CI/CD otimizado, além de documentar estrutura de diretórios e workflow de trabalho. A [coordenação de releases](./02-release-coordination.md) define processo de preparação, validação e deploy de novas versões incluindo ordem de deploy, smoke tests e procedimentos de rollback.

A [matriz de compatibilidade](./03-compatibility-matrix.md) documenta quais versões dos projetos são compatíveis entre si, servindo como referência para deployments e troubleshooting de integrações.
