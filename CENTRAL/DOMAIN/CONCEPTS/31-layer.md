# Camada Vetorial

Conjunto de geometrias criado por usuarios para representar informacoes geograficas adicionais. Pode conter infraestrutura, areas de risco, zoneamento, ou qualquer dado espacial relevante.

Camadas vetoriais complementam dados base do sistema. Permitem representar contexto local especifico que varia entre comunidades e projetos.

## Tipos de Geometria

Cada camada aceita um tipo de geometria - pontos, linhas ou poligonos. Todos os elementos da camada devem ser do mesmo tipo para consistencia.

## Estilo

Configuracao visual define cores, espessuras e icones para renderizacao. Rede de agua aparece azul, areas de risco em vermelho, equipamentos publicos como marcadores.

## Atributos

Elementos podem ter propriedades descritivas alem da geometria. Poste tem numero e tipo de transformador. Trecho de via tem nome e largura. Flexibilidade atende necessidades variadas.

## Exportacao

Camadas podem ser exportadas em formatos padrao GIS para uso em outras ferramentas. Importacao permite trazer dados de sistemas externos.
