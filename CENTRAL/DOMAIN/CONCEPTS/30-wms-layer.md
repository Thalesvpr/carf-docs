# Camada WMS

Camada individual servida por servidor WMS, configurada para exibicao em mapas do sistema. Pode ser ortofoto, imagem de satelite, ou mapa base.

Cada servidor pode ter multiplas camadas. Administrador seleciona quais sao relevantes e configura como devem ser exibidas na interface.

## Configuracao Visual

Opacidade controla transparencia, permitindo ver camadas sobrepostas. Ordem de empilhamento define qual camada fica por cima. Visibilidade inicial define se aparece ativa por padrao.

## Controle de Acesso

Camadas podem ser restritas por papel. Ortofoto com informacoes sensiveis pode ser visivel apenas para gestores. Mapa base publico fica visivel para todos.

## Associacao com Comunidade

Camadas podem ser vinculadas a comunidades especificas. Ao abrir comunidade, sistema ativa automaticamente a ortofoto correspondente.

## Comparacao

Usuarios podem ativar multiplas camadas simultaneamente. Comparar ortofoto recente com anterior revela mudancas no terreno ao longo do tempo.
