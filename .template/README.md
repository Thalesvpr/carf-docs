# Templates

Documentos normativos que definem a forma padrao de cada tipo de arquivo no vault. Cada template especifica regras de escrita, limites de tamanho, secoes obrigatorias e padroes proibidos. O plugin de validacao usa esses templates para garantir conformidade.

A pasta contem o [template de ADR](./ADR-000-template.md) para decisoes arquiteturais e o [template de README](./README.template.md) para arquivos de indice de pastas. Novos templates devem seguir a mesma estrutura: frontmatter com regras de validacao, secao de regras em texto, e conteudo-guia com perguntas implicitas.

Templates pendentes incluem User Stories, Requisitos Funcionais, Use Cases e documentos de dominio.
