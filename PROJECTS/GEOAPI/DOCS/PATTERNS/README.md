# PATTERNS

Padroes arquiteturais e de design do projeto GEOAPI e ecossistema CARF.

O [01-mobile-offline-first](./01-mobile-offline-first.md) descreve a estrategia offline-first para sincronizacao com aplicativos mobile como REURBCAD. O [02-gis-spatial-patterns](./02-gis-spatial-patterns.md) documenta os padroes de processamento geoespacial utilizados pelo GEOGIS plugin QGIS. O [03-clean-architecture](./03-clean-architecture.md) define a estrutura de camadas do backend. O [04-cqrs](./04-cqrs.md) estabelece a separacao entre comandos e queries. O [05-repository-uow](./05-repository-uow.md) documenta os padroes de acesso a dados. O [06-domain-events](./06-domain-events.md) define eventos de dominio para comunicacao entre aggregates. O [07-frontend-patterns](./07-frontend-patterns.md) estabelece padroes para aplicacoes frontend.
