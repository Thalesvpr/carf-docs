# AlertDialog

Modal de confirmacao que bloqueia interacao ate resposta. Baseado em @radix-ui/react-alert-dialog. Compound components: AlertDialog, AlertDialogTrigger, AlertDialogContent, AlertDialogHeader, AlertDialogTitle, AlertDialogDescription, AlertDialogFooter, AlertDialogAction, AlertDialogCancel. Acessibilidade: role="alertdialog", focus trap sem Escape para fechar (requer acao explicita). Uso: confirmacao de exclusao, acoes irreversiveis.
