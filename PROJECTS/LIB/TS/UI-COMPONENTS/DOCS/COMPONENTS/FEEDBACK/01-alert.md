# Alert

Caixa de mensagem para informacoes importantes. Compound components: Alert, AlertTitle, AlertDescription. Props: variant (default/destructive). Estilo: borda lateral colorida, icone opcional. Acessibilidade: role="alert" (implica aria-live="assertive"), anunciado imediatamente por screen readers. Uso: erros de validacao, avisos importantes, mensagens de sucesso.
