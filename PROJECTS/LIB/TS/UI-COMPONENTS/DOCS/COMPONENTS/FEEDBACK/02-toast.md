# Toast

Notificacao temporaria nao-bloqueante. Baseado em @radix-ui/react-toast. Hook useToast() para disparar. Compound components: ToastProvider, Toast, ToastTitle, ToastDescription, ToastAction, ToastClose. Props: variant, duration, open/onOpenChange. Posicao: bottom-right por padrao. Acessibilidade: role="status", aria-live="polite". Uso: confirmacoes de acao, feedback de salvamento.
