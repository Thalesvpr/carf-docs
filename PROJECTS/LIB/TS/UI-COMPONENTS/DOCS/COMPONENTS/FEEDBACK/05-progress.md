# Progress

Barra de progresso para indicar andamento de operacoes. Baseado em @radix-ui/react-progress. Props: value (0-100), max. Estilo: barra horizontal com preenchimento animado. Acessibilidade: role="progressbar", aria-valuenow, aria-valuemin, aria-valuemax, aria-valuetext opcional. Uso: upload de arquivos, processamento, carregamento de dados.
