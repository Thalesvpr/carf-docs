# Tabs

Navegacao em abas para alternar entre paineis de conteudo. Baseado em @radix-ui/react-tabs. Compound components: Tabs, TabsList, TabsTrigger, TabsContent. Props: value/onValueChange (controlled), defaultValue. Acessibilidade: role="tablist"/"tab"/"tabpanel", aria-selected, setas para navegar, Enter/Space para selecionar. Uso: formularios multi-etapa, configuracoes categorizadas.
