# Accordion

Paineis expansiveis para mostrar/ocultar conteudo. Baseado em @radix-ui/react-accordion. Compound components: Accordion, AccordionItem, AccordionTrigger, AccordionContent. Props: type (single/multiple), value/onValueChange, collapsible. Acessibilidade: aria-expanded, aria-controls, Enter/Space para toggle. Animacao via accordion-down/up. Uso: FAQs, menus laterais, configuracoes agrupadas.
