# Card

Container com borda e sombra para agrupar conteudo relacionado. Compound components: Card, CardHeader, CardTitle, CardDescription, CardContent, CardFooter. Estilo: bg-card, rounded-lg, border, shadow-card. Hover opcional com shadow-card-hover. Uso: paineis de informacao, formularios, listagens. Composicao flexivel permite qualquer combinacao de subcomponentes.
