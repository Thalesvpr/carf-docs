# Separator

Linha divisoria para separacao visual de conteudo. Baseado em @radix-ui/react-separator. Props: orientation (horizontal/vertical), decorative. Estilo: bg-border, 1px de espessura. Acessibilidade: role="separator" quando nao decorativo, aria-orientation. Uso: dividir secoes, separar itens de menu, organizar cards.
