# ScrollArea

Container com scrollbars customizados. Baseado em @radix-ui/react-scroll-area. Compound components: ScrollArea, ScrollBar. Props: type (auto/always/scroll/hover), scrollHideDelay. Estilo: scrollbar fino, arredondado, cor muted. Acessibilidade: mantém navegacao por teclado e scroll nativo. Uso: listas longas, paineis laterais, areas de conteudo com altura fixa.
