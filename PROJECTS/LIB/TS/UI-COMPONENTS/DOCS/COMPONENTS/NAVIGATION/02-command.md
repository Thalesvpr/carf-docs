# Command

Paleta de comandos estilo Ctrl+K com busca integrada. Baseado em cmdk. Compound components: Command, CommandInput, CommandList, CommandEmpty, CommandGroup, CommandItem, CommandSeparator. Props: filter customizavel. Estilo: Dialog com input de busca, lista filtrada. Acessibilidade: setas para navegar, Enter para selecionar. Uso: busca global, navegacao rapida, acoes.
