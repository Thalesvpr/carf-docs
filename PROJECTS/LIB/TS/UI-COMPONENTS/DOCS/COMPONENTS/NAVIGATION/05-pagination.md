# Pagination

Navegacao entre paginas de dados. Compound components: Pagination, PaginationContent, PaginationItem, PaginationLink, PaginationPrevious, PaginationNext, PaginationEllipsis. Props: page, totalPages, onPageChange. Estilo: botoes numerados com prev/next. Acessibilidade: nav com aria-label="pagination", aria-current="page". Integra com TanStack Table para paginacao de tabelas.
