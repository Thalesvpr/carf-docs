# Breadcrumb

Navegacao hierarquica mostrando caminho atual. Compound components: Breadcrumb, BreadcrumbList, BreadcrumbItem, BreadcrumbLink, BreadcrumbPage, BreadcrumbSeparator, BreadcrumbEllipsis. Estilo: links com separator (/ ou >). Acessibilidade: nav com aria-label="breadcrumb", aria-current="page" no item atual. Uso: indicar localizacao em hierarquias profundas.
