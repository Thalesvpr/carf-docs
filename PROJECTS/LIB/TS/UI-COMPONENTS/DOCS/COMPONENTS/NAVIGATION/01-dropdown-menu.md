# DropdownMenu

Menu suspenso acionado por clique. Baseado em @radix-ui/react-dropdown-menu. Compound components: DropdownMenu, DropdownMenuTrigger, DropdownMenuContent, DropdownMenuItem, DropdownMenuCheckboxItem, DropdownMenuRadioGroup, DropdownMenuRadioItem, DropdownMenuSeparator, DropdownMenuLabel, DropdownMenuSub. Acessibilidade: role="menu", setas para navegar, Enter para selecionar, Escape para fechar, typeahead.
