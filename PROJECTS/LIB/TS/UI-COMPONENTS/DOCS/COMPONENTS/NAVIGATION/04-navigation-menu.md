# NavigationMenu

Menu horizontal com dropdowns para navegacao principal. Baseado em @radix-ui/react-navigation-menu. Compound components: NavigationMenu, NavigationMenuList, NavigationMenuItem, NavigationMenuTrigger, NavigationMenuContent, NavigationMenuLink. Estilo: horizontal, dropdowns com animacao. Acessibilidade: role="navigation", setas para navegar, Enter para abrir submenus.
