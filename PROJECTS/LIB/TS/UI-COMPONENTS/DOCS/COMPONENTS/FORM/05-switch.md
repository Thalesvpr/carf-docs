# Switch

Toggle booleano com visual de interruptor deslizante. Baseado em @radix-ui/react-switch. Props: checked/onCheckedChange (controlled), defaultChecked (uncontrolled), disabled. Visual: thumb desliza, background muda de cor. Diferenca do Checkbox: Switch para acoes imediatas (on/off), Checkbox para selecao. Acessibilidade: role="switch", aria-checked, Space para toggle.
