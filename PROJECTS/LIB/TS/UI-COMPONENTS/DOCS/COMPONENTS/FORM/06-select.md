# Select

Dropdown para selecao de opcao unica. Baseado em @radix-ui/react-select. Compound components: Select, SelectTrigger, SelectValue, SelectContent, SelectItem, SelectSeparator, SelectGroup, SelectLabel. Props: value/onValueChange (controlled), defaultValue, disabled, placeholder. Acessibilidade: role="combobox", setas para navegar, Enter para selecionar, Escape para fechar, typeahead.
