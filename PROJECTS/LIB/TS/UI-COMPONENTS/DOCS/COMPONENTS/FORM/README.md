# Form Components

Componentes de formulario baseados em Radix UI com estilizacao CARF. Inclui Button para acoes, Input e Textarea para campos de texto, Label para acessibilidade, Checkbox e Switch para toggles booleanos, Select para dropdowns. Todos suportam estados disabled e controlled/uncontrolled com API detalhada via JSDoc no codigo fonte.
