# Textarea

Campo de entrada de texto multi-linha. Baseado em textarea nativo HTML. Props: rows (altura inicial), placeholder, disabled, value/onChange (controlled), defaultValue (uncontrolled), maxLength. Redimensionavel verticalmente. Integra com React Hook Form. Acessibilidade: associar com Label, aria-invalid para erros. Uso: descricoes, comentarios, observacoes.
