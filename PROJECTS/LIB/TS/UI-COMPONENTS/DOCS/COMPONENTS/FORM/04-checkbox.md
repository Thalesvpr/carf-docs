# Checkbox

Toggle booleano com visual de caixa de selecao. Baseado em @radix-ui/react-checkbox. Props: checked/onCheckedChange (controlled), defaultChecked (uncontrolled), disabled. Estados: unchecked, checked, indeterminate. Acessibilidade: role="checkbox", aria-checked, Space para toggle. Indicador visual via icone Check. Uso: aceite de termos, filtros multiplos, selecao em tabelas.
