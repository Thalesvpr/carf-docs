# Input

Campo de entrada de texto single-line. Baseado em input nativo HTML com estilizacao CARF. Props: type (text, email, password, number, tel, url), placeholder, disabled, value/onChange (controlled), defaultValue (uncontrolled). Integra com React Hook Form via register() ou Controller. Acessibilidade: associar com Label via htmlFor/id, aria-invalid para erros, aria-describedby para mensagens.
