# Label

Rotulo acessivel para campos de formulario. Baseado em @radix-ui/react-label para associacao automatica com inputs. Props: htmlFor (obrigatorio para associar ao input). Estilo: texto pequeno (text-sm), font-medium, cursor pointer. Uso obrigatorio para acessibilidade WCAG. Nunca usar placeholder como substituto de label.
