# Button

Componente de botao com variantes semanticas. Variants: default (primary), destructive (vermelho), outline (borda), secondary (cinza), ghost (transparente), link (sublinhado), success (verde), warning (amarelo). Sizes: sm (pequeno), default (medio), lg (grande), icon (quadrado). Props: variant, size, asChild (polimorfismo), disabled. Suporta icones via children. Acessibilidade: role="button", focus visible, aria-disabled.
