# UnitCard

Card para exibicao de unidade habitacional. Props: unit (Unit de @carf/tscore), onEdit, onDelete, onViewMap. Exibe: codigo (UN-XXX), endereco, area em m², quantidade de posseiros, StatusBadge. Acoes opcionais via dropdown ou botoes. Layout compacto para listagens, expandivel para detalhes. Baseado em Card generico com estrutura fixa para dados de unidade.
