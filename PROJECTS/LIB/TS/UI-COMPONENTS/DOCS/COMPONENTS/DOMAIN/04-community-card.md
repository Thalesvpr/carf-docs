# CommunityCard

Card para exibicao de comunidade/nucleo urbano informal. Props: community (Community de @carf/tscore), onEdit, onDelete, onViewUnits. Exibe: nome da comunidade, municipio, contagem de unidades, area total, StatusBadge do processo de regularizacao. Miniatura de mapa opcional. Acoes opcionais via dropdown. Baseado em Card generico com estrutura fixa para dados de comunidade.
