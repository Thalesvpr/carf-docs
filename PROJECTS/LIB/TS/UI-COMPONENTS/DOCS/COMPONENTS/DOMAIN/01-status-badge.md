# StatusBadge

Badge especializado para status de processos REURB. Props: status (pending, in_progress, approved, rejected, active, inactive, draft, archived). Cores semanticas automaticas: amarelo (pending), azul (in_progress), verde (approved/active), vermelho (rejected), cinza (inactive/draft/archived). Texto localizado em portugues. Baseado em Badge generico com variantes de dominio.
