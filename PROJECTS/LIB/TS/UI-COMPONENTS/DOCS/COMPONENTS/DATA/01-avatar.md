# Avatar

Imagem de perfil com fallback. Baseado em @radix-ui/react-avatar. Compound components: Avatar, AvatarImage, AvatarFallback. Props: src, alt para imagem; children para fallback (iniciais). Estilo: circular, tamanhos via className. Fallback exibido enquanto imagem carrega ou se falhar. Acessibilidade: role="img", aria-label quando sem alt. Uso: perfis de usuario, listas de participantes.
