# Popover

Conteudo flutuante acionado por clique. Baseado em @radix-ui/react-popover. Compound components: Popover, PopoverTrigger, PopoverContent, PopoverAnchor. Props: open/onOpenChange (controlled), modal. Estilo: bg-popover, rounded, shadow, z-50. Acessibilidade: focus trap, Escape para fechar. Diferenca do Tooltip: Popover para conteudo interativo (forms, menus), Tooltip para texto simples.
