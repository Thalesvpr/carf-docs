# Badge

Rotulo pequeno para status ou contagem. Props: variant (default, secondary, destructive, outline). Estilo: inline-flex, rounded-full, texto pequeno. Uso: status de processos, contadores, tags de categoria. Nao interativo - para acoes usar Button com size="sm". Cores semanticas via variant para indicar significado.
