# HoverCard

Preview de conteudo ao hover. Baseado em @radix-ui/react-hover-card. Compound components: HoverCard, HoverCardTrigger, HoverCardContent. Props: openDelay, closeDelay. Estilo: similar a Popover. Acessibilidade: abre com hover e focus, fecha ao sair. Uso: preview de perfis, detalhes de links, informacoes adicionais sem clique. Nao usar para conteudo critico (mobile nao tem hover).
