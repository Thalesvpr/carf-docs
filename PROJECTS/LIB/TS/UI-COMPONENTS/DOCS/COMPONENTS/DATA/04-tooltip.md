# Tooltip

Dica contextual ao hover/focus. Baseado em @radix-ui/react-tooltip. Requer TooltipProvider no layout. Compound components: Tooltip, TooltipTrigger, TooltipContent. Props: delayDuration, side, align. Estilo: bg-popover, sombra, z-50. Acessibilidade: role="tooltip", associado via aria-describedby. Uso: explicar icones, mostrar texto completo truncado, dicas de ajuda.
