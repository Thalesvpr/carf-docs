# Table

Tabela semantica para dados tabulares. Compound components: Table, TableHeader, TableBody, TableFooter, TableRow, TableHead, TableCell, TableCaption. Estilo: bordas sutis, hover em linhas, texto alinhado. Acessibilidade: elementos semanticos nativos (table, thead, tbody, th, td), scope em headers. Uso com TanStack Table para sorting, filtering, pagination. Caption para descricao acessivel.
