# Troubleshooting

Problemas comuns. Tailwind nao aplicado: adicionar node_modules/@carf/ui no content do tailwind.config.ts. Types nao encontrados: rodar build da lib, reinstalar node_modules. Componentes nao renderizam: verificar React 18 peer dependency. Storybook travando: limpar node_modules/.cache/storybook. Import circular: importar direto do arquivo, nao do index. Build falhando: rodar tsc --noEmit para ver erros de tipo. CSS variables nao funcionam: definir em globals.css com @layer base. Publicacao 401: configurar GITHUB_TOKEN em .npmrc.
