## Guias Rapidos

Para instalar a biblioteca, adicionar @carf/ui e @carf/tscore via bun add. Para rodar o Storybook em ambiente de desenvolvimento, acessar o diretorio SRC-CODE do projeto, instalar dependencias com bun install e iniciar com bun run storybook. Para publicar nova versao, executar build, rodar testes, incrementar versao via npm version patch, push das tags e publicar via npm publish.
