# Customization

Customizacao via CSS variables em globals.css das aplicacoes consumidoras. Cores em formato HSL sem virgulas (--primary: 220 90% 56%). Principais tokens: --primary, --secondary, --destructive, --background, --foreground, --border, --radius. Dark mode via classe 'dark' no html. Fontes via Next.js font com --font-sans e --font-mono. Temas contextuais via classes (.theme-admin). Componentes refletem mudancas automaticamente sem rebuild da biblioteca.
