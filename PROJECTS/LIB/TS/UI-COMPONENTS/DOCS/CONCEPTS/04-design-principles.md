# Design Principles

Oito principios. (1) Composition over Configuration: compound components ao inves de props bloat. (2) Accessibility First: ARIA e keyboard desde o inicio, nao como afterthought. (3) Mobile-First Responsive: design comeca no mobile, touch targets 44x44px minimo. (4) Design Tokens via CSS Variables: customizacao visual sem modificar codigo. (5) Performance by Default: imports granulares, lazy loading, bundle <80KB gzip. (6) Consistency via Storybook: todas variantes e estados documentados. (7) Testability via Testing Library: queries user-centric (role, label), nao implementacao. (8) Developer Experience: TypeScript strict, autocomplete completo, JSDoc, error messages uteis.
