# Terminology

Glossario tecnico. Atomic Design: metodologia Brad Frost (Atoms, Molecules, Organisms). Compound Component: padrao React com subcomponentes via static properties (Card.Header). Controlled vs Uncontrolled: state gerenciado externamente (value/onChange) vs interno (ref). Headless Component: logica sem estilo (Radix UI). Polymorphic: componente que renderiza como diferentes elementos via asChild. CSS Variables: tokens de tema customizaveis. Design Tokens: constantes visuais (cores, espacamento). Utility-First: metodologia Tailwind de classes unitarias. cn(): merge de classes com tailwind-merge. Server State: dados de API (TanStack Query). Client State: UI local (Zustand).
