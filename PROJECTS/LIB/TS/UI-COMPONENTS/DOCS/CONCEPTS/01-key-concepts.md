# Key Concepts

Tres conceitos fundamentais. Design Tokens: CSS variables definindo tema visual (--primary, --background, --radius) customizaveis por aplicacoes via globals.css. Atomic Design: hierarquia Atoms (Button, Input) compostos em Molecules (FormField = Label+Input+Error) formando Organisms (UnitCard, LoginForm). Compound Components: padrao React onde componente pai fornece contexto para subcomponentes (Card.Header, Card.Content, Card.Footer), permitindo composicao flexivel via Context API sem prop drilling.
