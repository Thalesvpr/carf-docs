# Tailwind Config

Configuracao Tailwind com tema CARF. Dark mode via classe. Cores: carf.primary (#2C5F2D) com escala 50-900, carf.secondary (#97BC62), carf.accent (#E63946), status (success, warning, error, info). Cores semanticas via CSS variables (--primary, --background, etc). Fontes: Inter (sans), JetBrains Mono (mono). Border radius via --radius variable. Animacoes: accordion-down/up, fade-in/out, slide-in-from-*. Sombras: card, card-hover, dropdown. Plugin tailwindcss-animate. Projetos consumidores usam presets: [carfConfig].
