# @carf/ui-native

Biblioteca de componentes React Native baseada em react-native-reusables seguindo filosofia shadcn de componentes copiados para o projeto. Usa NativeWind para manter mesmas classes Tailwind do web e rn-primitives como equivalente acessivel do Radix UI.

Esta biblioteca serve o aplicativo REURBCAD mobile fornecendo componentes de interface consistentes com a versao web @carf/ui. Desenvolvedores reutilizam conhecimento de Tailwind CSS. Componentes de dominio como StatusBadge e UnitCard compartilham tipos do @carf/tscore garantindo consistencia de dados entre plataformas.

A documentacao tecnica completa esta disponivel em [DOCS](./DOCS/README.md) incluindo decisoes arquiteturais, conceitos de acessibilidade e theming, guias de instalacao e referencia de todos componentes organizados por categoria.
