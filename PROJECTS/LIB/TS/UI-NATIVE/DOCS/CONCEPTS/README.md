# Conceitos

Documentacao dos conceitos fundamentais da biblioteca @carf/ui-native cobrindo design, acessibilidade e theming.

Os [conceitos-chave](./01-key-concepts.md) explicam principios de design da biblioteca. Apresenta filosofia shadcn de copiar componentes, organizacao em primitivos e dominio, e integracaso com NativeWind.

A [acessibilidade](./02-accessibility.md) documenta praticas de acessibilidade mobile. Cobre gerenciamento de foco, navegacao por teclado virtual, anuncios para leitores de tela e contraste de cores.

O [theming](./03-theming.md) descreve sistema de temas customizaveis. Explica variaveis CSS, dark mode, customizacao por tenant e persistencia de preferencias.
