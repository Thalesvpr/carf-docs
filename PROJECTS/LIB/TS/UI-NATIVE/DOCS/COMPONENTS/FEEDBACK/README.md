# Componentes de Feedback

Componentes para comunicacao com usuario via alertas, notificacoes e dialogos.

O componente [Alert](./01-alert.md) exibe mensagens inline com icone e variantes de severidade. Suporta default, destructive, warning e success. Usado para feedback contextual em formularios.

O componente [Toast](./02-toast.md) exibe notificacoes temporarias no topo ou fundo da tela. Desaparece automaticamente apos timeout configuravel. Permite acao opcional para desfazer.

O componente [Dialog](./03-dialog.md) exibe modal sobreposto para confirmacoes e formularios. Gerencia foco automaticamente. Usa rn-primitives para acessibilidade completa.

O componente [AlertDialog](./04-alert-dialog.md) exibe dialogo bloqueante para confirmacoes que requerem acao explicita. Suporta variantes default e destructive com accessibilityRole alertdialog.

O componente [Progress](./05-progress.md) exibe indicador de progresso linear ou circular com modo indeterminado. Suporta tamanhos sm, default e lg com accessibilityRole progressbar.

O componente [OfflineIndicator](./06-offline-indicator.md) exibe barra de status de conectividade com cores semanticas. Indica online, offline e syncing com contagem de operacoes pendentes.
