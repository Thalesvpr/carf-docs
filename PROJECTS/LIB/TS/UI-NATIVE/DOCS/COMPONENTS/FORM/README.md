# Componentes de Formulario

Componentes para entrada de dados em formularios React Native.

O componente [Button](./01-button.md) renderiza botao com variantes visuais e estados de loading. Suporta variantes default, outline, ghost e destructive. Integra com acessibilidade via accessibilityRole button.

O componente [Input](./02-input.md) fornece campo de texto com estilos consistentes. Suporta ref forwarding para integracao com react-hook-form. Inclui estados de erro e disabled.

O componente [Checkbox](./03-checkbox.md) gerencia selecao booleana com visual customizado. Usa rn-primitives para acessibilidade. Suporta estados checked, unchecked e indeterminate.

O componente [Switch](./04-switch.md) alterna entre dois estados com animacao. Util para preferencias on/off. Inclui labels acessiveis para leitores de tela.
