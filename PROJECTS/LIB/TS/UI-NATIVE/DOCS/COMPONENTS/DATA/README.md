# Componentes de Dados

Componentes para exibicao de informacoes e status visual.

O componente [Avatar](./01-avatar.md) exibe imagem circular de usuario com fallback para iniciais. Suporta diferentes tamanhos e indicador de status online.

O componente [Badge](./02-badge.md) exibe etiqueta pequena com texto e variante de cor. Usado para categorias, contadores e status generico.
