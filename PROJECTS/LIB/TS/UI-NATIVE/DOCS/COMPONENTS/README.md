# Componentes

Documentacao de todos componentes React Native da biblioteca @carf/ui-native organizados por categoria funcional.

Componentes de [formulario](./FORM/README.md) incluem Button, Input, Checkbox, Switch, Select e Textarea para entrada de dados. Seguem padroes de acessibilidade mobile com labels e estados corretos.

Componentes de [layout](./LAYOUT/README.md) incluem Card, Separator, Tabs, Accordion, BottomSheet e ScreenContainer para estruturacao de conteudo. Adaptados para interacoes touch e gestos nativos.

Componentes de [feedback](./FEEDBACK/README.md) incluem Alert, Toast, Dialog, AlertDialog, Progress e OfflineIndicator para comunicacao com usuario. Gerenciam foco e anuncios para leitores de tela.

Componentes de [dados](./DATA/README.md) incluem Avatar e Badge para exibicao de informacoes. Adaptados para diferentes tamanhos de tela.

Componentes de [navegacao](./NAVIGATION/README.md) incluem BottomNavigation com tabs adaptados por role e Header com acoes contextuais e indicador offline. Integram com sistema de roles do @carf/tscore.

Componentes de [dominio](./DOMAIN/README.md) sao especificos do CARF. StatusBadge, UnitCard, HolderCard, CommunityCard, MapComponent, CameraOverlay e SignatureCanvas integram com tipos do @carf/tscore.

Cada componente documenta props, variantes, comportamento iOS vs Android e consideracoes de acessibilidade WCAG 2.1 AA. Componentes usam NativeWind para estilizacao com classes Tailwind.
