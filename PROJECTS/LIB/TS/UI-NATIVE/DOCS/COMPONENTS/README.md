# Componentes

Documentacao de todos componentes React Native da biblioteca @carf/ui-native organizados por categoria funcional.

Componentes de [formulario](./FORM/README.md) incluem Button, Input, Checkbox e Switch para entrada de dados. Seguem padroes de acessibilidade mobile com labels e estados corretos.

Componentes de [feedback](./FEEDBACK/README.md) incluem Alert, Toast e Dialog para comunicacao com usuario. Gerenciam foco e anuncios para leitores de tela.

Componentes de [dados](./DATA/README.md) incluem Avatar e Badge para exibicao de informacoes. Adaptados para diferentes tamanhos de tela.

Componentes de [dominio](./DOMAIN/README.md) sao especificos do CARF. StatusBadge, UnitCard e HolderCard integram com tipos do @carf/tscore.

Cada componente documenta props, variantes, exemplos de uso e consideracoes de acessibilidade. Componentes usam NativeWind para estilizacao com classes Tailwind.
