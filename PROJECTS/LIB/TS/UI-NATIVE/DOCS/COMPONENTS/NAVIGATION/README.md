# Componentes de Navegacao

Componentes para navegacao entre telas e secoes da aplicacao REURBCAD React Native.

O componente [BottomNavigation](./01-bottom-navigation.md) renderiza barra de navegacao inferior com tabs adaptados por role do usuario. FIELD_COORDINATOR visualiza Mapa, Unidades, Equipe e Perfil; FIELD_CADASTRATOR acessa mapa diretamente como tela principal. Integra com sistema de roles do @carf/tscore.

O componente [Header](./02-header.md) fornece cabecalho de tela com botao de voltar, titulo, acoes contextuais (sync, notificacoes) e indicador de conectividade. Substitui o header padrao do React Navigation com design especifico do REURBCAD.
