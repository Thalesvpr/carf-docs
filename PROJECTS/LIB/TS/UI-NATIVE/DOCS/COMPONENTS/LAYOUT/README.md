# Componentes de Layout

Componentes para estruturacao e organizacao de conteudo em telas React Native.

O componente [Card](./01-card.md) fornece container visual com variantes default, elevated e outlined. Compoe com CardHeader, CardContent e CardFooter para layouts flexiveis.

O componente [Separator](./02-separator.md) renderiza linha divisoria horizontal ou vertical entre elementos de conteudo. Componente minimal para separacao visual.

O componente [Tabs](./03-tabs.md) organiza conteudo em abas com suporte a swipe horizontal. Tab bar com scroll e indicador animado de aba ativa.

O componente [Accordion](./04-accordion.md) exibe paineis expansiveis com animacao via LayoutAnimation. Suporta modos single e multiple para abertura de paineis.

O componente [BottomSheet](./05-bottom-sheet.md) fornece painel inferior deslizante com snap points para interacoes contextuais, especialmente no mapa.

O componente [ScreenContainer](./06-screen-container.md) encapsula SafeAreaView, StatusBar e KeyboardAvoidingView em container unico para uso consistente em todas as telas do REURBCAD.
