# Decisoes Arquiteturais

Registro de ADRs que fundamentam decisoes tecnicas da biblioteca @carf/ui-native.

A [ADR-001](./ADR-001-react-native-reusables.md) define adocao de react-native-reusables como base para componentes mobile. Estabelece NativeWind para estilizacao com classes Tailwind e rn-primitives para primitivos acessiveis. Rejeitou alternativas como Tamagui e gluestack-ui por APIs diferentes do shadcn que exigiriam reaprendizado.

Novas decisoes arquiteturais que impactam a biblioteca devem ser registradas como ADRs seguindo template padrao com secoes Contexto, Decisao, Consequencias e Alternativas Rejeitadas.
