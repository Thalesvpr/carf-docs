# Arquitetura

Documentacao arquitetural da biblioteca @carf/ui-native descrevendo estrutura de componentes, configuracao e integracao.

O [overview](./01-overview.md) apresenta visao geral da arquitetura baseada em react-native-reusables com NativeWind. Descreve organizacao em componentes primitivos e de dominio, sistema de temas e principios de design.

A [configuracao NativeWind](./02-nativewind-setup.md) detalha setup necessario para projetos Expo. Cobre instalacao de dependencias, configuracao de babel preset, tailwind.config.js e integracao com Expo.

A [integracao](./03-integration.md) documenta como consumir biblioteca em aplicativos Expo. Descreve importacao de componentes, configuracao de tema e uso de componentes de dominio com tipos tscore.
