# Documentacao @carf/ui-native

Documentacao tecnica completa da biblioteca de componentes React Native baseada em react-native-reusables com NativeWind.

A documentacao esta organizada em seis secoes principais. As [decisoes arquiteturais](./ADRs/README.md) registram escolhas tecnicas como adocao de react-native-reusables e NativeWind. A [arquitetura](./ARCHITECTURE/README.md) descreve estrutura de componentes, configuracao NativeWind e integracao com projetos Expo.

Os [conceitos](./CONCEPTS/README.md) explicam principios de design, acessibilidade e sistema de theming. Os [componentes](./COMPONENTS/README.md) documentam todos elementos de interface organizados por categoria funcional. Os [guias praticos](./HOW-TO/README.md) orientam desenvolvedores na instalacao e configuracao inicial.

A biblioteca implementa componentes primitivos para formularios, feedback e exibicao de dados. Componentes de dominio CARF como StatusBadge, UnitCard e HolderCard integram com tipos do @carf/tscore. Todos componentes seguem principios WCAG para acessibilidade mobile.
