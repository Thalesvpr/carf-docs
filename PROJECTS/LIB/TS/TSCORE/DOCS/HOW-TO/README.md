# Guias Praticos

Tutoriais orientados a tarefas para desenvolvedores que precisam usar, desenvolver ou publicar a biblioteca @carf/tscore.

O guia [usando tipos](./01-using-types.md) ensina como consumir a biblioteca em cada projeto do ecossistema. Cobre configuracao de .npmrc para GitHub Packages, instalacao via Bun e exemplos de importacao de validacoes e tipos. Demonstra integracao com React Hook Form, TanStack Query e WatermelonDB.

O guia [desenvolvimento local](./02-local-development.md) orienta contribuidores que precisam modificar a biblioteca. Explica uso de npm link para testar mudancas localmente antes de publicar, workflow de desenvolvimento com hot reload e como desfazer link para restaurar versao publicada.

O guia [publicacao](./03-publishing.md) documenta processo de release no GitHub Packages. Detalha versionamento semantico, criacao de tags Git, pipeline CI/CD automatizado e verificacao de publicacao bem-sucedida. Inclui troubleshooting para problemas comuns de autenticacao e permissao.

Cada guia segue formato passo-a-passo com contexto inicial, procedimento detalhado e verificacao de sucesso. Exemplos usam projetos reais GEOWEB, REURBCAD, ADMIN e WEBDOCS para demonstrar uso em producao.
