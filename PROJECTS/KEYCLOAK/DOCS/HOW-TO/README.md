# HOW-TO

Guias praticos para desenvolvimento, deployment e operacao do Keycloak CARF cobrindo desde setup inicial ate producao com alta disponibilidade. Cada guia segue formato passo-a-passo com comandos concretos.

O [develop-themes](./01-develop-themes.md) documenta o fluxo planejado de desenvolvimento com Keycloakify React/TypeScript (migracao futura; tema atual usa FreeMarker). O [deploy-extensions](./02-deploy-extensions.md) cobre deploy de SPIs Java via Maven e Docker. O [setup-dev-environment](./03-setup-dev-environment.md) guia o setup local com Docker Compose, realm import e IDE debugging. O [build-custom-image](./04-build-custom-image.md) explica build da imagem Docker customizada com themes e providers. O [update-keycloak-version](./05-update-keycloak-version.md) documenta atualizacao de versao com changelog e staged rollout. O [configure-production](./06-configure-production.md) cobre producao com PostgreSQL, HTTPS, clustering e backup.
