# UC-008: Importar Shapefile

Caso de uso para importacao em massa de unidades habitacionais a partir de arquivo Shapefile ou GeoJSON. O fluxo envolve ADMIN ou TECHNICAL_USER fazendo upload, mapeando campos e validando dados antes da importacao.

O [fluxo principal](./UC-008-importar-shapefile.md) documenta a importacao via Shapefile. O fluxo alternativo FA-001 cobre importacao GeoJSON como formato alternativo. Os fluxos de excecao tratam arquivo invalido (FE-001), SRID desconhecido (FE-002), duplicatas (FE-003) e geometrias invalidas (FE-004).
