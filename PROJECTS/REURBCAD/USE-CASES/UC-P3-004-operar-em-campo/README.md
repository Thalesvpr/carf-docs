# UC-P3-004: Operar em Campo

Este caso de uso pertence a PARTE 3 do workflow mestre e descreve o fluxo operacional completo em campo. Com a comunidade selecionada no UC-P3-003, o agente executa as operacoes de cadastro que incluem navegacao GPS, acoes no lote como criar, editar, mover e excluir, preenchimento de formularios de cadastro, captura de assinatura digital, leitura de QR Code, anexacao de documentos e armazenamento local dos dados coletados. Os dados ficam armazenados localmente ate a sincronizacao com o backend no UC-005.
