# REURBCAD - Aplicativo Mobile

Aplicativo mobile React Native Expo para coleta offline dados cadastrais campo GPS fotos titulares sincronizacao inteligente. Stack: React Native Expo WatermelonDB SQLite react-native-maps expo-camera expo-location OAuth2 PKCE custom URL scheme secure storage.
