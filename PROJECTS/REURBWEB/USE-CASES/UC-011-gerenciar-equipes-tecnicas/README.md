# UC-011: Gerenciar Equipes Tecnicas

Caso de uso para criar e gerenciar equipes tecnicas de trabalho. O fluxo envolve ADMIN ou MANAGER organizando colaboradores em grupos, definindo lideres responsaveis e atribuindo comunidades especificas para cada equipe.

O [fluxo principal](./UC-011-gerenciar-equipes-tecnicas.md) documenta a criacao e configuracao de equipes. Os fluxos alternativos cobrem edicao de equipe existente (FA-001) e alteracao de lider (FA-002). Os fluxos de excecao tratam nome duplicado (FE-001) e lider invalido ou inativo (FE-002).
