# WEBDOCS - Documentação Técnica

Documentação técnica do projeto WEBDOCS, portal de documentação Astro 4 + Starlight para o ecossistema CARF. Este diretório contém especificações, arquitetura e guias para desenvolvimento e manutenção do portal.

A [arquitetura](./ARCHITECTURE/README.md) documenta stack tecnológico, estrutura do projeto, autenticação Keycloak, rotas protegidas, renderização híbrida e deploy. Os [conceitos](./CONCEPTS/README.md) explicam fundamentos de Astro, Starlight, Content Collections, MDX, Decap CMS e Pagefind. As [especificações](./SPECS/README.md) definem estrutura de cada seção do portal incluindo frontmatter schemas e navegação.

As [features](./FEATURES/README.md) documentam funcionalidades especiais como status page, Swagger embutido, banner de notificações e diagramas Mermaid. As [diretrizes de conteúdo](./CONTENT-GUIDELINES/README.md) guiam tom de voz, estrutura de página e acessibilidade. A [validação](./VALIDATION/README.md) especifica checks de qualidade no CI.

Os [templates](./TEMPLATES/README.md) fornecem modelos para novos documentos. A [integração](./INTEGRATION/README.md) documenta conexões com Keycloak, ui-components e GEOAPI. Os [guias práticos](./HOW-TO/README.md) ensinam tarefas comuns de desenvolvimento. Os [ADRs](./ADRs/README.md) registram decisões arquiteturais do projeto.
