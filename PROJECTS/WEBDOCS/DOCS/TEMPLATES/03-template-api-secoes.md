# Template de API - Secoes Complementares

Secoes de permissoes, exemplos de uso, e ver tambem. Documento complementar a 03-template-api.md.

## Secao de Permissoes por Role

Tabela com colunas Operacao, User, Field Agent, Analyst, Admin, Super Admin. Celulas com Sim ou Nao indicando permissao. Notas de rodape para condicoes especiais (por exemplo, apenas recursos proprios nao aprovados). Aside tipo caution para restricoes como recursos aprovados nao editaveis.

## Secao de Exemplos de Uso

Cenarios comuns como h3 com passos numerados em linguagem de negocio. Cenarios tipicos: cadastrar apos coleta em campo (agente coleta, sincroniza, recurso criado pendente, analista revisa), e atualizar dados incompletos (analista identifica, solicita, agente recebe notificacao, completa e reenvia).
