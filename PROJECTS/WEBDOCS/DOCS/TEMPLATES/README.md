# Templates

Modelos de página para criação de novos documentos no WEBDOCS garantindo consistência de estrutura e metadados.

O [template de guia](./01-template-guia.md) serve para páginas explicativas da seção /guia/. O [template de manual](./02-template-manual.md) serve para documentação de uso das aplicações. O [template de API](./03-template-api.md) serve para documentação conceitual de endpoints. O [template dev](./04-template-dev.md) serve para documentação técnica da seção protegida /dev/.
