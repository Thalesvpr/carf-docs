# Templates

Modelos de pagina para criacao de novos documentos no WEBDOCS garantindo consistencia de estrutura e metadados.

O [template de guia](./01-template-guia.md) serve para paginas explicativas da secao /guia/. O [template de manual](./02-template-manual.md) serve para documentacao de uso das aplicacoes. O [template de API](./03-template-api.md) serve para documentacao conceitual de endpoints. O [template dev](./04-template-dev.md) serve para documentacao tecnica da secao protegida /dev/.
