# Content Guidelines

Diretrizes para criação de conteúdo no WEBDOCS garantindo consistência de tom, estrutura e acessibilidade em toda documentação.

O [tom e voz](./01-tom-e-voz.md) define como escrever para diferentes audiências (usuários finais, analistas, desenvolvedores). A [estrutura de página](./02-estrutura-pagina.md) especifica anatomia padrão de documentos. A [acessibilidade](./03-acessibilidade.md) cobre requisitos WCAG para texto, imagens e navegação. As [diretrizes de mídia](./04-midia.md) orientam uso de fotos, vídeos e diagramas.
