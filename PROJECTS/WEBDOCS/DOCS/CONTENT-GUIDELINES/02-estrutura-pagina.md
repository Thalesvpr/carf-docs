# Estrutura de Página

Páginas seguem estrutura consistente facilitando navegação e compreensão. Frontmatter define metadados, introdução contextualiza o conteúdo, corpo desenvolve o tema, e conclusão orienta próximos passos.

Frontmatter obrigatório inclui title (exibido no browser tab e sidebar), description (usada em SEO e previews), e lastUpdated (data da última modificação). Campos opcionais incluem audience (user ou dev), section (para navegação), e tableOfContents (controle de exibição).

Introdução no primeiro parágrafo após título resume o que página cobre e para quem é destinada. Leitor deve entender em segundos se página responde sua dúvida. Evitar introduções longas que atrasam acesso ao conteúdo principal.

Corpo usa headings hierárquicos (h2, h3, h4) para organizar conteúdo. Cada heading deve ser compreensível fora de contexto para funcionar no table of contents. Parágrafos curtos de 3-5 linhas facilitam leitura em tela. Listas para sequências de itens relacionados.

Conclusão opcional em páginas de guia orienta próximos passos com links para páginas relacionadas. Seção "Ver também" ou "Próximos passos" agrupa links relevantes. Evitar conclusões redundantes que apenas repetem introdução.

Callouts destacam informações importantes usando componente apropriado: note para informações complementares, tip para sugestões úteis, warning para precauções, e danger para ações destrutivas ou irreversíveis.
