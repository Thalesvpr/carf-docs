# Integration

Documentação das integrações do WEBDOCS com outros sistemas do ecossistema CARF.

A integração com [Keycloak](./01-keycloak.md) documenta autenticação OAuth2/OIDC e proteção da seção /dev/ por role. A integração com [ui-components](./02-ui-components.md) explica como tema visual é importado da biblioteca compartilhada. A integração com [GEOAPI health](./03-geoapi-health.md) cobre consumo dos endpoints /health para status page. A integração com [GEOAPI swagger](./04-geoapi-swagger.md) documenta fetch e renderização da especificação OpenAPI.
