# Seção Guia

Seção /guia/ orienta usuários sobre como usar a documentação e entender conceitos básicos do sistema CARF. Primeira parada para novos usuários antes de explorar manuais específicos.

Estrutura de pastas em src/content/docs/guia/ contém arquivos Markdown organizados por tópico. Ordem de navegação definida por campo order no frontmatter. Página index.mdx serve como landing da seção com visão geral e links para páginas principais.

Conteúdo esperado inclui página de boas-vindas explicando propósito do portal e público alvo, guia de navegação ensinando usar busca sidebar e atalhos, glossário de termos REURB-S e REURB-E usados na documentação, e FAQ com perguntas frequentes de usuários.

Tom de escrita é acolhedor e didático assumindo que leitor pode não ter experiência com sistemas de regularização fundiária. Evitar jargão técnico, explicar siglas na primeira ocorrência, usar exemplos concretos do contexto brasileiro.

Frontmatter padrão define section como guia, audience como user, e sidebar com order sequencial. Title deve ser descritivo indicando claramente o que página ensina.

Links para outras seções direcionam usuário conforme necessidade: analistas para manuais do REURBWEB, agentes de campo para manuais do REURBCAD, e gestores para manuais do REURBMASTER.

Manutenção inclui revisar FAQ periodicamente adicionando perguntas recorrentes de suporte, atualizar capturas de tela quando interface muda, e validar links para outras seções.
