# Specs

Especificacoes detalhadas de cada secao do portal WEBDOCS definindo estrutura, conteudo esperado e navegacao.

O [frontmatter schema](./01-frontmatter-schema.md) define campos obrigatorios e opcionais para todos documentos. As especificacoes de secao cobrem [guia](./02-secao-guia.md), [sistema](./03-secao-sistema.md), [manuais](./04-secao-manuais.md), [api](./05-secao-api.md), [dev](./06-secao-dev.md), [status](./07-secao-status.md), e [changelog](./08-secao-changelog.md). Os [assets](./10-assets-imagens.md) definem organizacao de screenshots e videos.
