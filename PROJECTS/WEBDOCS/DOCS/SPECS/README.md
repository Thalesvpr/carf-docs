# Specs

Especificações detalhadas de cada seção do portal WEBDOCS definindo estrutura, conteúdo esperado e navegação.

O [frontmatter schema](./01-frontmatter-schema.md) define campos obrigatórios e opcionais para todos documentos. As especificações de seção cobrem [guia](./02-secao-guia.md), [sistema](./03-secao-sistema.md), [manuais](./04-secao-manuais.md), [api](./05-secao-api.md), [dev](./06-secao-dev.md), [status](./07-secao-status.md), e [changelog](./08-secao-changelog.md). A [navegação](./09-sidebar-navegacao.md) especifica estrutura do sidebar. Os [assets](./10-assets-imagens.md) definem organização de screenshots e vídeos.
