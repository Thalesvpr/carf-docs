# Features

Funcionalidades especiais do WEBDOCS alem da documentacao estatica padrao.

A [status page](./01-status-page.md) documenta implementacao de health checks em tempo real dos servicos CARF. O [Swagger embutido](./02-swagger-embutido.md) especifica integracao da documentacao interativa da API. O [banner de notificacoes](./03-banner-notificacoes.md) cobre sistema de avisos editaveis via CMS. O [CMS Decap](./04-cms-decap.md) detalha configuracao do sistema de edicao visual. Os [diagramas Mermaid](./05-mermaid-diagramas.md) explicam como criar e renderizar diagramas no conteudo.
