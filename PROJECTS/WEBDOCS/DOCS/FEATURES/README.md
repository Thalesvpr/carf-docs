# Features

Funcionalidades especiais do WEBDOCS além da documentação estática padrão.

A [status page](./01-status-page.md) documenta implementação de health checks em tempo real dos serviços CARF. O [Swagger embutido](./02-swagger-embutido.md) especifica integração da documentação interativa da API. O [banner de notificações](./03-banner-notificacoes.md) cobre sistema de avisos editáveis via CMS. O [CMS Decap](./04-cms-decap.md) detalha configuração do sistema de edição visual. Os [diagramas Mermaid](./05-mermaid-diagramas.md) explicam como criar e renderizar diagramas no conteúdo.
