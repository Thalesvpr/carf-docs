# ADRs

Architecture Decision Records documentando decisões técnicas significativas do projeto WEBDOCS. Cada ADR registra contexto, decisão, alternativas consideradas e consequências.

O [ADR-001](./ADR-001-astro-starlight.md) justifica escolha de Astro + Starlight como framework. O [ADR-002](./ADR-002-role-based-content.md) explica conteúdo protegido por role dev. O [ADR-003](./ADR-003-conteudo-proprio.md) documenta decisão de não sincronizar com CENTRAL. O [ADR-004](./ADR-004-git-based-cms.md) justifica Decap CMS para edição visual. O [ADR-005](./ADR-005-status-page.md) define implementação de health checks. O [ADR-006](./ADR-006-swagger-embutido.md) especifica integração do Swagger na seção dev.
