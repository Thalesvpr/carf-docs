# Validation

Especificacao dos checks de qualidade executados no CI para garantir consistencia e funcionamento do WEBDOCS.

A [validacao de conteudo](./01-validacao-conteudo.md) cobre checks de links e frontmatter. A [validacao de acessibilidade](./02-validacao-a11y.md) especifica testes WCAG automatizados. A [validacao de performance](./03-validacao-performance.md) define thresholds de Lighthouse. O [pipeline de CI](./04-ci-pipeline-overview.md) documenta configuracao do GitHub Actions.
