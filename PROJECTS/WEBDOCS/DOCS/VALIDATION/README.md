# Validation

Especificação dos checks de qualidade executados no CI para garantir consistência e funcionamento do WEBDOCS.

A [validação de conteúdo](./01-validacao-conteudo.md) cobre checks de links e frontmatter. A [validação de acessibilidade](./02-validacao-a11y.md) especifica testes WCAG automatizados. A [validação de performance](./03-validacao-performance.md) define thresholds de Lighthouse. O [pipeline de CI](./04-ci-pipeline.md) documenta configuração do GitHub Actions.
