# How-To

Guias práticos para tarefas comuns de desenvolvimento e manutenção do WEBDOCS.

O [setup do projeto](./01-setup-projeto.md) guia configuração inicial do ambiente de desenvolvimento. O [adicionar página](./02-adicionar-pagina.md) ensina criar novos documentos com frontmatter correto. O [configurar auth](./03-configurar-auth.md) documenta setup da integração Keycloak. O [configurar CMS](./04-configurar-cms.md) explica setup do Decap CMS. O [adicionar status check](./05-adicionar-status-check.md) ensina incluir novo serviço na status page. O [embed video](./06-embed-video.md) mostra como incluir vídeos YouTube. O [criar diagrama](./07-criar-diagrama.md) documenta sintaxe Mermaid para diagramas. O [deploy Vercel](./08-deploy-vercel.md) cobre configuração de deploy e variáveis de ambiente. O [troubleshooting](./09-troubleshooting.md) documenta resolução de problemas comuns.
