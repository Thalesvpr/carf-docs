# Architecture

Documentacao da arquitetura tecnica do WEBDOCS cobrindo stack, estrutura do projeto, autenticacao, renderizacao e deploy.

A [visao geral](./01-overview.md) apresenta stack tecnologico e diagrama de componentes. A [estrutura do projeto](./02-estrutura-projeto.md) documenta organizacao de pastas em SRC-CODE. A [autenticacao](./03-autenticacao.md) explica integracao com Keycloak. As [rotas protegidas](./04-rotas-protegidas.md) detalham middleware de autorizacao. A [renderizacao](./05-renderizacao.md) cobre modo hibrido SSG/SSR. O [build e deploy](./06-build-deploy.md) documenta pipeline de CI/CD e Vercel.
