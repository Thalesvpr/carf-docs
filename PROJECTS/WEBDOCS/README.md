# WEBDOCS

Portal de documentação Astro 4 + Starlight com guias de usuário, tutoriais e referência técnica do sistema CARF. Autenticação via Keycloak protege seção /dev/ acessível apenas para usuários com role dev contendo Swagger interativo, documentação técnica interna e guias de contribuição. Conteúdo editável via Decap CMS (Git-based) sem necessidade de editar arquivos diretamente.
