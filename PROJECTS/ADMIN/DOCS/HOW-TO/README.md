# How-To - ADMIN

Esta secao reune os guias praticos para desenvolvimento, build, testes e resolucao de problemas do console administrativo ADMIN. Os guias cobrem desde a configuracao inicial do ambiente local ate a execucao de testes end-to-end e diagnostico de problemas comuns em desenvolvimento e producao.

O ponto de partida recomendado e o guia de setup do ambiente de desenvolvimento, que orienta a instalacao de dependencias, configuracao de variaveis de ambiente e inicializacao dos servicos de infraestrutura necessarios. Apos o ambiente configurado, o guia de build e execucao detalha as etapas para gerar builds de producao e validar localmente antes do deploy. O guia de testes documenta a estrategia de testes end-to-end com Playwright cobrindo fluxos criticos do sistema. Por fim, o guia de troubleshooting apresenta os problemas mais frequentes com diagnostico e solucao para cada caso.
