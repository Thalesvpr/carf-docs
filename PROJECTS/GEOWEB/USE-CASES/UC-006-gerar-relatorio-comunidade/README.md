# UC-006: Gerar Relatorio de Comunidade

Caso de uso para geracao de relatorios consolidados com estatisticas de uma comunidade. O fluxo envolve MANAGER ou ADMIN selecionando parametros (comunidade, periodo, secoes) e recebendo relatorio em PDF ou Excel.

O [fluxo principal](./UC-006-gerar-relatorio-comunidade.md) documenta a geracao completa. Os fluxos alternativos cobrem geracao rapida para comunidades pequenas (FA-001) e agendamento recorrente para envio automatico (FA-002). Os fluxos de excecao tratam timeout de geracao (FE-001), dados insuficientes (FE-002) e erro ao gerar PDF (FE-003).
