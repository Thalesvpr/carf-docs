# STD-003: Convencoes de Nomenclatura

## Regra

Arquivos usam prefixos por tipo: RF-XXX para requisitos funcionais, UC-XXX para casos de uso, US-XXX para user stories, RNF-XXX para requisitos nao funcionais, ADR-XXX para decisoes, STD-XXX para standards. Demais arquivos usam prefixo numerico 01-nome.md. Nomes em kebab-case minusculo. Termos tecnicos seguem grafia oficial: PostgreSQL, PostGIS, Keycloak, React Native, .NET, TypeScript.

## Justificativa

Prefixos permitem identificacao rapida do tipo de documento e ordenacao logica em listagens de diretorio.

## Aplicacao

Aplica-se a todos os arquivos markdown exceto README.md. Pastas em CENTRAL usam UPPERCASE. Arquivos em SRC-CODE e .scripts sao isentos.
