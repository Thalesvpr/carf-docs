# STANDARDS

Convencoes e padroes obrigatorios do projeto CARF garantindo consistencia entre todos os arquivos em CENTRAL e PROJECTS. Estes padroes sao validados automaticamente pelos scripts em .scripts/ que auditam a documentacao e reportam violacoes.

Os padroes de documentacao definem estrutura e formato de arquivos markdown. O [status de arquivo](./STD-001-file-status-convention.md) especifica metadados obrigatorios no frontmatter. A [estrutura de README](./STD-002-readme-structure.md) padroniza organizacao de pastas. As [convencoes de nomenclatura](./STD-003-naming-conventions.md) definem prefixos como RF-XXX e UC-XXX. Os [tipos de documento](./STD-004-document-types.md) especificam secoes obrigatorias por tipo. As [diretrizes de conteudo](./STD-005-content-guidelines.md) definem limites de tamanho e densidade. As [convencoes de links](./STD-006-link-conventions.md) padronizam paths relativos.

Os padroes de desenvolvimento definem praticas de codigo e processos. O [estilo de codigo](./STD-007-code-style.md) estabelece formatacao para .NET e TypeScript. As [convencoes de commit](./STD-008-commit-conventions.md) definem formato Conventional Commits. O [design de API](./STD-009-api-design.md) especifica convencoes REST. O [versionamento](./STD-010-versioning.md) define Semantic Versioning para releases.
